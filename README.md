# Michael Ngo Professional Portfolio

A personal professional portfolio showcasing bid management, proposal strategy, procurement analysis, business intelligence, workflow improvement, and executive reporting.

## Featured work

- Interactive Bid Intelligence Dashboard built around 60 fictional opportunities
- End-to-end Queensboro Transit Authority procurement case study
- Resume and career experience
- Verified credentials and professional development portfolio

All organizations, opportunities, prices, results, and narratives used in portfolio demonstrations are fictional and were created from scratch. No employer or client records were copied or renamed.

## Technology

- Next.js
- React
- TypeScript
- Responsive custom CSS
- Vercel-ready deployment

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in a browser.

## Production build

```bash
npm run build
npm run start
```
